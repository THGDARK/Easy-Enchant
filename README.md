# EasyEnchant

A powerful and user-friendly Minecraft plugin that simplifies item enchanting through an intuitive GUI interface.

## ✨ Features

- **Intuitive GUI Interface**: Easy-to-use graphical interface for enchanting items
- **Smart Item Detection**: Automatically displays compatible enchantments for the item in your main hand
- **Level Selection**: Simple enchantment level selection with visual feedback
- **Safe Confirmation**: Confirm/cancel options to prevent accidental enchanting
- **Fully Configurable**: Customize messages, GUI layout, and permissions
- **Permission System**: Fine-grained control over plugin access and usage

## 📦 Installation

1. Download the latest `EasyEnchant.jar` from the releases section
2. Place the JAR file in your server's `plugins` folder
3. Restart your server or use a plugin manager to load the plugin
4. (Optional) Configure the plugin settings in `config.yml`

## 🎮 Usage
1. Hold the item you want to enchant in your main hand
2. Type `/easyenchant` or `/ee` to open the enchantment GUI
3. Click on an enchantment from the available options
4. Select your desired enchantment level
5. Confirm or cancel the enchantment process

## 🔒 Permissions
- `easyenchant.use` - Allows access to basic plugin features (default: true)
- `easyenchant.admin` - Grants access to administrative commands

## 🔧 Configuration
Edit `config.yml` to customize:
- GUI layout and appearance
- Message texts and formats
- Enchantment level limits
- Permission requirements

- Works with Bukkit/Spigot/Paper servers
- Supports Minecraft versions 1.21 and higher
